PromptBase Profile Exporter

$ pb @acb --format html

Turns a public PromptBase profile into a catalog you own: every prompt's title, description, price, and counters, in the format your next tool reads.

  • catalog.htmlOne self-contained page you can search; it loads nothing from other sites.
  • catalog.jsonEvery field, for scripts. NDJSON too, one record per line.
  • catalog.csvFor spreadsheets, with formula protection when you ask for it.
  • catalog.mdFor notes and wikis, or one Markdown file per prompt with front matter.
  • catalog.txtTitles and descriptions, nothing else.

See it on a real profile

Install

It needs Python 3.10 or newer and nothing else: the standard library only.

git clone https://github.com/IACBI/promptbase-profile-exporter.git
cd promptbase-profile-exporter
uv tool install .            # or: python -m pip install -e .

Run it the way you work

From the command line, with pb. Compare against last week's catalog with --compare, refresh one in place with --update-file, or convert a saved one offline with pb-convert. CLI guide

In the browser, with pb-web: a local form with a preview, bound to your own machine. Web UI guide

On a schedule, with the GitHub Action: export every day, get the changes in the run summary, keep a history of sales and views, or publish a dashboard like this one. Action guide

What it reads

Only what PromptBase already shows anyone: no account, no cookies, no private endpoints. Every release is built in public and signed, and you can check where a file came from with gh attestation verify.
