Own your PromptBase catalog.

Turn a public PromptBase profile into a catalog you control: every prompt's title, description, price and counters, in the format your next tool reads, with history over time.

See a live catalog Install in a minute

Six formats, one source of truth

Every format is built from the same listings. Pick the one your tool reads; the command takes one format per run.

catalog.html

One self-contained page you can search. It loads nothing from other sites.

catalog.json

Every field, for scripts and pipelines.

catalog.ndjson

One record per line, for streams and log tools.

catalog.csv

For spreadsheets, with formula protection when you ask for it.

catalog.md

For notes and wikis, or one Markdown file per prompt with front matter.

catalog.txt

Titles and descriptions as plain text, easy to read and diff.

Three ways to run it

Use the command line for one-off work, the browser for a quick preview, or the GitHub Action to run on a schedule.

Command line

pb

Compare against last week's catalog with --compare, refresh one in place with --update-file, or convert a saved catalog offline with pb-convert.

Install

Python 3.10 or newer is the only requirement. There are no third-party packages to install.

  1. Get the source

    Clone the repository from GitHub, or download a release from the latest release.

    git clone https://github.com/IACBI/promptbase-profile-exporter.git
cd promptbase-profile-exporter

  2. Install the commands

    With uv, or with pip into the current environment.

    uv tool install .            # or: python -m pip install -e .

  3. Export a profile

    Pass a username, an @name or a profile URL.

    pb @acb --mode all --format html

Privacy and trust

It reads what PromptBase already shows anyone, and nothing it shouldn't.

  • No account, no cookies, no private endpoints. It reads the same public data the PromptBase website serves, and nothing else.
  • Standard library only. The runtime has no third-party dependencies, so there is less code between you and your data to trust.
  • Signed releases. Each release is built by a workflow and carries a build-provenance attestation. Check a download with gh attestation verify.
